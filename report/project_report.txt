Domain‑Robust Semantic Segmentation for Synthetic Desert Environments
TEAM ASTITVA: Atharv Datar · Raunak Sharma · Raghav Mishra · Aditi Sharma

1. Introduction
Semantic segmentation enables pixel‑level scene understanding by assigning a semantic class label to every pixel in an image. In autonomous desert navigation scenarios, such fine‑grained perception is essential for obstacle detection, terrain classification, and safe path planning.

Desert and off‑road environments present unique challenges:

High visual similarity between terrain classes

Irregular vegetation structures

Texture overlap between dry grass, soil, and clutter

Strong lighting variation

To address these challenges, we developed a deep learning–based multi‑class segmentation system trained on synthetic desert environment data. The model is optimized using the Intersection over Union (IoU) metric, which directly evaluates segmentation quality.

2. Dataset Overview
The dataset was generated using FalconEditor and contains synthetic desert twin environments.

Structure

3. Methodology
3.1 Model Architecture
We implemented a DINOv2 Vision Transformer backbone (ViT‑S/14) combined with a custom convolutional segmentation head.

Architecture Components:
Backbone (Frozen initially):

Pretrained DINOv2 ViT‑S/14

Extracts high‑level semantic patch embeddings

Patch size: 14×14

Segmentation Head:

Convolutional layers

Depthwise separable convolutions

Upsampling via bilinear interpolation

Final 1×1 classifier

This hybrid design allows:

Strong semantic representation from pretrained transformer

Efficient pixel reconstruction through convolutional decoding

3.2 Training Strategy
To maximize IoU performance, we implemented:

1️⃣ Loss Function
A combined loss:

Cross‑Entropy Loss

Dice Loss (IoU‑aligned optimization)

This improves:

Class imbalance handling

Boundary accuracy

Small object segmentation

2️⃣ Data Augmentation
Random Horizontal Flip

Color Jitter

Controlled resizing (multiple of patch size 14)

This improves domain robustness and prevents overfitting.

3️⃣ Optimization
Optimizer: AdamW

Learning rate: 1e‑4

Mixed Precision (AMP) for faster GPU training

Best model checkpoint saved based on Validation IoU

5. Results
Training Observations
Validation IoU improved consistently across epochs.

Combined Dice + Cross‑Entropy loss stabilized boundary predictions.

Fine‑tuning improved generalization on unseen desert twins.

Key Performance Metrics
Validation IoU steadily increased during training.

Best model saved based on highest validation IoU.

Pixel accuracy remained stable while IoU improved.

The model demonstrated strong terrain separation capability across vegetation and ground classes.

6. Failure Case Analysis
Despite strong performance, certain limitations were observed:

Confusion between Dry Grass and Landscape

Minor misclassification near object boundaries

Thin structures (logs, flowers) occasionally under‑segmented

These errors are expected due to:

Texture similarity

Class imbalance

Resolution downsampling constraints

Future improvements could include:

Higher resolution training

Boundary-aware loss functions

Partial backbone fine‑tuning
